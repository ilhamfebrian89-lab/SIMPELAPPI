# SIMPELAPPI KPI Baseline 2026 Q3

## Tujuan

Dokumen ini menetapkan baseline KPI awal untuk periode 3 bulan pertama operasional terukur.

Periode baseline:

- Agustus 2026
- September 2026
- Oktober 2026

## KPI Baseline Target

### Reliability

- Availability: >= 99.5%
- API 5xx Rate: <= 1.0%
- P95 Dashboard: <= 3.0 detik
- P95 Write Endpoint: <= 2.0 detik

### Delivery

- Deployment Frequency: >= 2 release minor per bulan
- Change Failure Rate: <= 10%
- Lead Time for Change: <= 7 hari

### Incident Response

- MTTA SEV-1: <= 10 menit
- MTTA SEV-2: <= 20 menit
- MTTR SEV-1: <= 120 menit
- MTTR SEV-2: <= 240 menit
- Incident Recurrence Rate (30 hari): <= 5%

### Security

- Failed Login Spike Detection: <= 5 menit
- Privileged Access Review Completion: 100% per bulan
- Critical Vulnerability Remediation: <= 7 hari
- High Vulnerability Remediation: <= 14 hari

### Support

- Ticket SLA Adherence: >= 95%
- First Response SEV-1/SEV-2: <= 15 menit
- CSAT Operasional: >= 4.2 / 5

## RAG Threshold

Gunakan status RAG untuk memudahkan eskalasi:

- Green: KPI memenuhi target
- Amber: deviasi <= 10% dari target
- Red: deviasi > 10% dari target
